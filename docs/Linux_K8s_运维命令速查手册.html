系统信息

查看系统/内核信息
基础
uname -a                   # 内核版本、主机名、架构
cat /etc/os-release        # 操作系统发行版详情
hostnamectl                # 主机名、OS、内核一览
uptime                     # 运行时间、负载均值
CPU / 内存 / 负载
监控
top                        # 实时进程和资源监控
htop                       # 增强版 top（需安装）
free -h                    # 内存使用情况
lscpu                      # CPU 详细信息
vmstat 1 5                 # 虚拟内存统计
sar -u 1 5                 # CPU 使用率采样
📁

文件与目录管理

文件操作
基础
ls -lah                    # 列出文件（含隐藏、权限、大小）
cp -r src/ dst/            # 递归复制
mv old new                 # 移动/重命名
rm -rf dir/                # 强制递归删除（慎用）
find / -name "*.log" -mtime +30  # 查找30天前的log
find / -size +100M         # 查找大于100MB的文件
du -sh /var/*              # 各子目录大小
文本查看与处理
基础
cat file                   # 查看全部内容
head -n 50 file            # 前50行
tail -f /var/log/syslog    # 实时追踪日志
grep -rn "error" /var/log/ # 递归搜索error
awk '{print $1,$4}' file   # 提取列
sort file | uniq -c | sort -rn  # 统计排序重复行
wc -l file                 # 统计行数
压缩与解压
基础
tar -czvf archive.tar.gz dir/   # 压缩tar.gz
tar -xzvf archive.tar.gz        # 解压tar.gz
unzip file.zip -d /target/      # 解压zip
⚙️

进程管理

查看与管理进程
运维
ps aux                     # 查看所有进程
ps aux | grep nginx        # 过滤指定进程
ps -eo pid,ppid,%cpu,%mem,cmd --sort=-%cpu | head  # 按CPU排序
kill PID                   # 优雅终止
kill -9 PID                # 强制终止
killall nginx              # 按名终止
nohup command &            # 后台运行
lsof -i :8080              # 查占用8080的进程
🌐

网络诊断

网络配置与连通性
网络
ip a                       # 查看网络接口和IP
ip r                       # 查看路由表
ping -c 4 8.8.8.8         # 测试连通性
traceroute google.com      # 追踪路由
dig example.com            # DNS查询
curl -I https://example.com  # HTTP响应头
端口与连接
网络
ss -tlnp                   # 所有监听TCP端口和进程
ss -s                      # 连接统计摘要
nc -zv host 80             # 测试端口是否开放
tcpdump -i eth0 port 80    # 抓包指定端口
iptables -L -n             # 查看防火墙规则

磁盘与存储

磁盘空间与健康
存储
df -h                      # 文件系统使用情况
df -ih                     # inode使用情况
lsblk                      # 块设备树
fdisk -l                   # 磁盘分区详情
iostat -xm 1 5            # 磁盘I/O统计
smartctl -a /dev/sda       # SMART健康信息

用户与权限

用户管理
安全
whoami                     # 当前用户
id username                # 用户UID/GID
useradd -m -s /bin/bash user  # 创建用户
passwd user                # 设置密码
chmod 755 file             # 修改权限
chown -R user:group dir/   # 递归修改所有者

系统服务（systemd）

服务管理
运维
systemctl status nginx     # 查看服务状态
systemctl start|stop|restart nginx  # 启停重启
systemctl enable nginx     # 开机自启
systemctl list-units --failed  # 失败的服务
journalctl -u nginx -f     # 实时查看日志
journalctl -u nginx --since "1 hour ago"

集群管理

集群信息与上下文
集群
kubectl cluster-info               # 集群信息
kubectl get nodes -o wide          # 节点列表
kubectl top nodes                  # 节点CPU/内存
kubectl describe node <name>       # 节点详情
kubectl config get-contexts        # 所有上下文
kubectl config use-context <ctx>   # 切换集群
节点管理
运维
kubectl cordon <node>              # 不可调度
kubectl uncordon <node>            # 恢复调度
kubectl drain <node> --ignore-daemonsets --delete-emptydir-data
kubectl taint nodes <node> key=value:NoSchedule
kubectl label nodes <node> env=prod
📦

Pod 操作

查看与管理 Pod
Pod
kubectl get pods -A -o wide        # 所有Pod
kubectl get pods -l app=nginx      # 按标签筛选
kubectl describe pod <name>        # Pod详情
kubectl delete pod <name>          # 删除Pod
kubectl delete pod <name> --force --grace-period=0
进入Pod / 日志
调试
kubectl exec -it <pod> -- /bin/bash
kubectl exec -it <pod> -c <container> -- /bin/bash
kubectl logs <pod> -f              # 实时日志
kubectl logs <pod> --tail=100      # 最近100行
kubectl logs <pod> --since=1h      # 最近1小时
kubectl logs <pod> --previous      # 崩溃前日志
kubectl cp <pod>:/path/file ./local
🚀

Deployment

部署与更新
部署
kubectl get deploy -A
kubectl apply -f deploy.yaml       # 应用配置
kubectl scale deploy <name> --replicas=5
kubectl set image deploy/<name> nginx=nginx:1.25
kubectl rollout status deploy/<name>
kubectl rollout undo deploy/<name> # 回滚
kubectl rollout restart deploy/<name>

故障排查

排查工具箱
排障
kubectl get pods | grep -v Running # 非Running Pod
kubectl get events --sort-by=.lastTimestamp
kubectl get events -n <ns> --field-selector type=Warning
kubectl top pods --sort-by=cpu
kubectl top pods --sort-by=memory
kubectl describe node <n> | grep -A5 Conditions
kubectl debug -it <pod> --image=busybox
常见异常：CrashLoopBackOff→logs --previous · ImagePullBackOff→检查镜像名 · Pending→资源不足 · OOMKilled→增加memory limits
